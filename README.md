# Zanjis-car-website-
A website about selling cars
Question 1: Website Creation

I created a personal car-sales website called **Zanji Mupeta Motors**. The website presents cars for sale and provides customers with vehicle information and a contact form for enquiries.

The website uses only HTML and demonstrates more than 25 different HTML elements and more than 15 HTML attributes. It also uses semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, `footer`, and `address`.

 Question 2: HTML Elements

 1. Five challenging elements

1. **`form`** - It required several related controls for collecting customer information.
2. **`table`** - It required a clear structure using `table`, `caption`, `thead`, `tbody`, `tr`, `th`, and `td`.
3. **`details`** - It allowed extra vehicle information to be hidden until the customer wants to view it.
4. **`figure`** - It helped organize vehicle images together with their captions.
5. **`fieldset`** - It grouped the contact form controls into one meaningful section.

### 2. Semantic elements

I used `header` for the website heading and navigation, `main` for the main page content, `section` for major content areas, `article` for individual cars, and `footer` for contact and copyright information. These elements make the page structure easier to understand.

 3. Most useful layout element

The `section` element was the most useful because it divided the website into clear areas such as Home, Cars for Sale, About, and Contact.

 Question 3: HTML Attributes

 1. Three essential attributes

- **`href`** - Used to connect navigation links to sections of the page.
- **`src`** - Used to specify the source of vehicle images.
- **`id`** - Used to identify sections and connect navigation links to them.

 2. `class` versus `id`

I used `id` for unique sections such as `home`, `cars`, `about`, and `contact`. I used `class` for elements that share the same type or purpose, such as the car cards.

 3. Attribute that improved user experience

The `alt` attribute was especially useful because it provides a text description of images if they cannot be displayed and improves accessibility.

 Question 4: Development Process

 1. Planning

I first planned the website as a car-sales site. I divided it into Home, Cars for Sale, About, Why Choose Us, Contact, and Footer sections. I then selected HTML elements that could represent each section.

 2. Testing and debugging

I opened the HTML file in a web browser after making changes. I checked that navigation links worked, images displayed correctly, the enquiry form contained the required fields, and the HTML structure was properly closed.

 3. Challenges

One challenge was making sure the website used enough different HTML elements and attributes while still keeping the content meaningful. I solved this by adding semantic sections, vehicle articles, a table, a details section, and a customer enquiry form.

Question 6: Code Quality & Best Practices

 1. Valid and error-free HTML

I checked that opening and closing tags matched, attributes were correctly written, and the page structure was organized logically. I also tested the page in a web browser.

 2. Clean and readable code

I used indentation, meaningful section names, comments where useful, semantic HTML, descriptive `alt` text, and consistent formatting.
